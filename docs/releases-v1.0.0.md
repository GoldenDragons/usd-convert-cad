# v1.0.0 — CAD → USD 中文批量桌面便携版

基于 NVIDIA `usd-convert-cad==0.3.0` 的 Windows 图形界面版本。

## 本版本功能

- 中文桌面界面，支持多选、追加和移除待转换文件。
- 按顺序批量转换，独立显示每个文件的状态。
- 24 项转换参数均提供中文说明，可按需勾选启用、修改或取消。
- 支持 USD、USDA、USDC、USDZ 输出和输出目录选择。
- 重名自动添加编号，保护已有文件。
- 实时日志、批次进度和取消入口。
- 随包提供 Python、OpenUSD 与 CAD 转换运行时，无需目标机器安装 Python 或 Omniverse Kit。

## 下载和启动

下载 `CADConverter-Windows-x64.zip`，完整解压后双击其中的 `CADConverter.exe`。
必须保留整个文件夹，包含 `_internal` 和 `runtime`；单独复制 EXE 无法运行。
`SHA256SUMS.txt` 用于验证下载文件完整性。

目标平台为 Windows 10/11 x64，不支持 32 位 Windows。
装配文件需要保留所引用的零部件与相对目录结构。
