# USD Convert CAD documentation

`usd-convert-cad` provides a Python wheel, command-line interface, and agent
skill for converting supported CAD, AEC, and interchange formats to OpenUSD.

Public documentation is maintained in these repository locations:

- [`README.md`](../../README.md): overview, setup, usage, supported formats, and
  support information.
- [`skills/omniverse-cad-to-usd/SKILL.md`](../../skills/omniverse-cad-to-usd/SKILL.md):
  canonical agent workflow.
- [`LIMITATIONS.md`](../../LIMITATIONS.md): platform, format, and conversion
  limitations.
- [`CHANGELOG.md`](../../CHANGELOG.md): release history.
- [`SECURITY.md`](../../SECURITY.md): vulnerability reporting instructions.

This directory provides an index of the project's public documentation. Public
API, compatibility, behavior, or support changes should update the relevant
documents above as part of the same reviewed change.
